    About the barrier on this page: instructions given by colour alone
    What the barrier is
    The instruction says to use “the code shown in pink”. The 4 codes look alike apart from their text colour. Nothing else marks the right one.
    What happens
    If you cannot see or tell apart the colours, you have to guess between 4 similar codes. Screen readers read out the codes without any colour, so the instruction cannot be followed at all.
    Who it can affect
    People with colour vision deficiency, blind and partially sighted people, people using high contrast or forced colours modes, and anyone using a monochrome or poor-quality screen.
    WCAG 2.2
    1.4.1 Use of Color (A); 1.3.3 Sensory Characteristics (A).
    How the accessible version fixes it
    The code is given in text (“Your coupon code is: GIV-20-FREE”). Colour is only decoration and the hint explains what format is accepted.
