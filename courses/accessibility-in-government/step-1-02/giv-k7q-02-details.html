    About the barrier on this page: missing form labels
    What the barrier is
    The fields have placeholder text but no <label> element. The placeholder is the only instruction.
    What happens
    As soon as you type, the instruction disappears, so you cannot check what a field is for or what format it needs. Screen readers may announce just “edit text”: some browsers use the placeholder as a fallback name, but this is not reliable. Selecting the instruction text does not move focus to the field, because there is no label to select.
    Who it can affect
    Screen reader and voice control users (who need a name to say or hear), people with memory or attention difficulties, and anyone who is interrupted halfway through.
    WCAG 2.2
    1.3.1 Info and Relationships (A); 3.3.2 Labels or Instructions (A); 4.1.2 Name, Role, Value (A).
    How the accessible version fixes it
    Each field has a visible <label> linked with “for” and “id”, a hint linked with aria-describedby, and an error summary that links to each field.
