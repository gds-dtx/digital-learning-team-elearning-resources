    About the barrier on this page: unclear error messages
    What the barrier is
    If anything is wrong, one general message appears at the top of the form: “Something went wrong. Please try again.” There is also no hint about the date format the service needs (DD/MM/YYYY, in the future).
    What happens
    The message appears above the fold, away from the Submit button, so you may not notice it. It does not say which answer is wrong or how to fix it. Focus stays on the button and screen readers are not told anything changed. You have to guess.
    Who it can affect
    Screen reader and magnifier users, people with cognitive or learning disabilities, people with anxiety, and anyone in a hurry – such as someone racing a 60-second countdown.
    WCAG 2.2
    3.3.1 Error Identification (A); 3.3.3 Error Suggestion (AA); 4.1.3 Status Messages (AA).
    How the accessible version fixes it
    A format hint before you start. An error summary that receives focus and links to each problem. A specific message next to each field, linked with aria-describedby. “Error:” added to the page title.
